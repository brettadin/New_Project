# 0.0 — Project Vision and Requirements: Master Index

## Introduction

This document provides the central overview and navigation structure for the application's vision, scientific requirements, functionality, architecture, user experience and development approach.

The Foundations documentation is organized into thirteen sections. Each section addresses a distinct area of the project, with individual subsection documents providing the detailed requirements.

Use this index to locate relevant documentation and understand how the different areas of the project relate to one another. The individual section and subsection documents remain the authoritative sources for their respective requirements.

## Documentation Organization and Use

- Each main section and subsection is maintained in its own Markdown document.
- This index provides navigation and brief descriptions; detailed requirements are maintained in the corresponding documents.
- Section and subsection numbering and titles should remain consistent between this index and the individual files.
- Update this index when documents are added, renamed, reorganized or substantially changed.
- Use the individual documents as the authoritative sources for requirements and their supporting details.
- Maintain clear distinctions between established requirements, future possibilities, deferred decisions and unresolved questions in the relevant documents.

**General principle:** This index should remain a concise and accurate guide to the Foundations documentation, not a duplicate of the requirements contained within it.

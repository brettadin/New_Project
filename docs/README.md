# Project Documentation Index

This is the central documentation index for the astronomy research application. It identifies major documents, their locations, and their purposes, organized by documentation category.

## Authoritative Sources

| Document | Location | Purpose |
|---|---|---|
| **Foundation (authoritative requirements)** | `docs/Foundation/` | Read-only governing specification. Defines the application's intended requirements, goals, constraints, and development philosophy. Declared read-only by `AGENTS.md`. |
| **Master Development Roadmap** | `docs/MASTER_DEVELOPMENT_ROADMAP.md` | Single authoritative source for overall development planning and progress. Tracks stages, priorities, dependencies, and status. |
| **Development Log** | `docs/development/DEVELOPMENT_LOG.md` | Rolling chronological development record. |
| **AGENTS.md** | `AGENTS.md` | Project instructions. Governing project-level guidance (not a Foundation document). |

## Documentation Categories

| Category | Location | Contents |
|---|---|---|
| Requirements | `docs/Foundation/` | Vision, scientific scope, capabilities, data, integrity, structure, education, community, platform, AI partner responsibilities, knowledge management, planning boundaries, outstanding questions. |
| Scientific knowledge | `docs/science/` | Scientific principles, research findings, methods, procedures, limitations, unresolved questions for the initial capability. |
| Architecture | `docs/architecture/` | System architecture, component responsibilities, data models, internal interfaces, architectural decisions. |
| Technical research | `docs/technical/` | Technology and framework evaluations, library investigations, database research, platform compatibility findings. |
| Development records | `docs/development/` | Chronological log, decisions, problems, test reports, research reviews, handoffs, improvements. |
| External resources | `docs/resources/` | External scientific databases, archives, software, libraries, reference links. |
| Templates | `docs/templates/` | Standardized formats for recurring documentation records. |

## Navigation

- Start with `docs/MASTER_DEVELOPMENT_ROADMAP.md` for development status and next steps.
- Consult `docs/Foundation/` for authoritative requirements.
- Check `docs/development/decisions/` for approved and pending decisions.
- This index must be updated when significant documents are created, renamed, moved, or retired (§11.2.6).
